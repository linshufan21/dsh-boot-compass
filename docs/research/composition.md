# 科幻 HUD 启动动画 · 评图笔记（4.5s / 16:9 / 深空黑）

## 1. 网格与比例
- **分带优先于 12 列**：中央罗盘区 = 屏高 60–70% 的正方模块，左右侧栏各占 3 列、顶/底条各占 1 行；全屏 `12 列 × 8px 基线`（Müller-Brockmann 的模块化网格 = 列+行+固定槽沟，他本人样品常用 8/20/32 个场）[来源](https://raw.githubusercontent.com/shenxingy/Clade/main/configs/skills/muller-brockmann-grid-systems/SKILL.md)。
- **1920×1080 量化**：槽沟 24px，列宽 ≈144px，边距 48/64px（2.5–3.3% 屏宽）。Material 的 12 列体系规定 gutter/margin 取 8/16/24/40dp，且栏沟不必等宽 [来源](https://m1.material.io/layout/responsive-ui.html)。广播安全区按 EBU R95：内容留 5% 边（≈96×54px）[来源](https://tech.ebu.ch/docs/r/r095.pdf)。
- **尺度**：间距用 4/8px 基数 + 1.25 比例阶梯（4·8·12·16·24·32·48·64）；字号阶梯取 1.25：11 / 14 / 18 / 22 / 28 / 36 / 64 / 100。Carbon 生产档位 12→14→16→20→28→32→42→54 可作参照 [来源](https://raw.githubusercontent.com/carbon-design-system/carbon/8263d2cc666b777f2c28a3ab3c8f4d1102bdd3b6/docs/migration/10.x-type.md)。

## 2. 视觉层级
- **对比手段优先级（明度 > 尺寸 > 运动 > 色彩 > 位置 > 字重）**：NN/g 把层级归为色彩/对比、尺度、分组三类，并强调"是明度与饱和度对比而非色相本身"造成层级 [来源](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/) —— 深空黑底上明度是唯一不会被色觉缺陷抹掉的通道，故排第一。
- **硬约束**：字号不超过 3 级（小/中/大），"最大者"最多 2 个 [同上]；颜色 ≤2 主 + 2 辅，对比变化 ≤3 档，"处处对比即无对比" [同上]。
- **焦点**：核心亮度 100%，环形/表盘刻度 60–70%，侧栏标签 40–60%，四角框线 15–25%。眯眼/5–10px 模糊测试后必须是核心先跳出来 [同上]。
- **密度**：可见信息团 ≤7 组、前景墨迹占屏面 12–25%，其余 75–88% 保持近黑；四栏各自独立成组，靠留白分组而非靠边框分组。

## 3. 对齐与光学修正
- **几何居中 ≠ 光学居中**：圆/三角视觉重量集中在最宽处与重心，同高会比方形显小，需放大约 **2–5%** 才"等重"；三角要向右偏几个百分点才像居中 [来源](https://github.com/manusco/wolfgang/blob/main/.agents/skills/design/designer/references/optical_craft.md)。
- **圆内文字/数字**：按 SVG 视框居中通常不居中，应居**可见墨迹**，圆形容器内单字再补 1–2% 径向微调；混排大数字与小标签时对齐**共享基线或光学中心**，不要对齐盒子 [同上]。
- **框线对齐**：圆角嵌套须同心得 `内半径 = 外半径 − padding`，否则角部"掐"；分隔首选发丝线（8–12% 透明，而非 1px 实灰）[同上]。
- **标题墨迹 vs 盒**：大字号有左边距空铅，盒在网格上而墨迹不在；需按字体实测 `actualBoundingBoxLeft` 补偿 [来源](https://raw.githubusercontent.com/shenxingy/Clade/main/configs/skills/muller-brockmann-grid-systems/SKILL.md)。

## 4. 留白 / 负空间
- 推荐区间：外围边距 ≥ 屏宽 5%，模块间空 = 1 个槽沟，组间空 = 2–3 个槽沟（相邻 1×、组间 3× 的间距节奏最能分组）[NN/g](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/)。
- 每个模块周边留 ≥50% 空场；"一屏只允许一个元素享受最大空白"——空白多者被读成一组也先被看 [同上]。
- **装饰框线何时是帮助**：当它承担"归属/共域"功能（把一组信息圈起来），或做安全区边界时用；当它只是"凑氛围"、与中心争明度、或叠到文字行上时是噪声。可删则删；空白与背景做不到分离时才加容器 [同上]。

## 5. 数据可视化
- **波形/缓冲条规范**：必须有 0 基线并锁定振幅量程（同一动画内比例不得变），否则等于"截断 y 轴"的谎言 [来源](https://raw.githubusercontent.com/aref-vc/tufte-claude-skill/main/principles.md)；条宽:间距 ≈ 1:1 ~ 1:2（2–3px 条 + 2–4px 空），轨道底槽 ≤20% 白，填充用主色。
- **data-ink ratio**：定义"若数据变了才会变的墨迹"= 数据墨；比值越高越好 [同上]。实践：删刻度、删大网格、删重影描边、删纯装饰性对称镜影波形（它不随数据变）；保留数值直标，用 sparkline 替代整块图表 [同上]。NN/g 亦把"过多相似明度/饱和度"列为层级杀手。

## 6. 字体排印
- 小标签全大写：字号 10–11px，字距 **+5–8%（0.5–0.8px）**，行距 1.4–1.6；大数字用 **0.9–0.95 负字距**、行距 1.0–1.1（Material 官方大字号 tracking −0.25px 量级、正文小字 +0.4~0.5px）[来源](https://raw.githubusercontent.com/hamen/material-3-skill/master/skills/material-3/references/typography-and-shape.md)。
- **等宽用于数字**：必须用等宽/表格数字（tabular numerals），否则数值跳动时位宽抖动、整行位移 [optical_craft](https://github.com/manusco/wolfgang/blob/main/.agents/skills/design/designer/references/optical_craft.md)。
- 字号阶梯 1.25 比例（11/14/18/22/28/36/64/100），同屏 ≤4 档；数字 100% 明度、标签 ≥45% 明度差。

## 7. 动效与构图配合
- **每拍一个焦点**：Material 的连续性规则是"过渡中只能有一个焦点元素掌控其余元素"，多元素共享即"无焦点的场景"，明确列为 Don't [来源](https://m1.material.io/motion/choreography.html)。
- **5 拍时间表**：0–0.9s 核心唤醒（仅一个光点，110→0 透明、0.8→1 缩放）；0.9–1.8s 环形自中心径向展开；1.8–2.8s 轨道汇聚（列表项错峰进入，**错峰间隔 ≤20ms**，单向由内向外）[同上]；2.8–3.7s 能量同步（亮度/波形归一）；3.7–4.5s 定格，最后 300ms 完全静止。
- **时长/缓动**：进场 250–400ms、退场 ~200ms（Material 大屏时长档 200–500ms）[来源](https://raw.githubusercontent.com/hamen/material-3-skill/master/skills/material-3/references/typography-and-shape.md)；ease-out `cubic-bezier(0.05,0.7,0.1,1)` 进场、ease-in-out `cubic-bezier(0.4,0,0.2,1)` 位移 [M1](https://m1.material.io/motion/duration-easing.html)。
- **视线引导**：所有入场元素沿"四角 → 边缘 → 中心"的径向汇聚，中心亮度最晚达到峰值，保证停留在核心。
- **定格帧 6 条件**：①中心/环/轨道同心（半径偏差 <2%）；②四角标记镜像对称；③文字基线共线；④左右模块位置固定、无残余动效；⑤中心区 ≥35% 屏宽且周边低饱和；⑥静置 300ms 无任何位移，可当静态界面直接使用。

## 8. 常见错误清单（12 条）
1. 四角框线太粗/太亮（>1.5px 或 >30% 明度），抢中心焦点。
2. 侧栏字号接近主视觉字号，出现第二个焦点（"最大者 ≤2 个"被违反）。
3. 全大写标签零字距，密读成一块灰。
4. 数字用比例字体，刷新时位宽抖动。
5. 波形无 0 基线、量程随动画变化，读成虚假剧烈波动。
6. 波形做左右对称镜影、纯装饰，不随数据变化（非数据墨）。
7. 刻度/网格线与数据同明度，1+1=3 噪点。
8. 表盘外圈文字几何居中、径向不居中，读着"歪"。
9. 圆角嵌套不同心，角部发紧。
10. 用 1px 硬灰线做分隔，而非 8–12% 发丝线。
11. 前景墨迹 >30%，深空黑变成灰面板，负空间失去聚焦作用。
12. 顶部/底部条同时用多种明度+色彩+加粗，底部与顶部争"第一个被看"；或定格帧仍有 1px 抖动/未对齐。
